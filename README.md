# trabajo-led

Web educativa e interactiva sobre:

- cómo se consiguió crear el LED azul (y por qué durante años se consideró casi imposible);
- cómo funciona un LED de color tipo RGB mediante un simulador visual.

## Ejecutar localmente

Puedes abrir `index.html` directamente en el navegador o usar un servidor simple:

```bash
python3 -m http.server 8000
```

Después visita: `http://localhost:8000`.
